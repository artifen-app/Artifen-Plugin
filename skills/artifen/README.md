# artifen

An Agent Skill that teaches an agent to build and host sites on [Artifen](http://localhost:3000): when to put something online there, how to start from plain files or the full-stack starting app, change files without losing anyone's work, publish, go back to an earlier version, and recover from errors.

| File | What it covers |
| --- | --- |
| `SKILL.md` | The tools and when to use each |
| `references/site-stack.md` | Writing code for a full-stack site |
| `references/errors.md` | What to do after each error |
| `references/shell.md` | The command line and Git |
| `references/page-data.md` | Saving data from a page |
| `references/limits.md` | What a site can do in one request, and plan allowances |
